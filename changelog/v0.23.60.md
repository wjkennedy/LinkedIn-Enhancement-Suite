## [v0.23.60](https://github.com/wjkennedy/LinkedIn-Enhancement-Suite/releases/v0.23.60)

### New Features

- Add an Auto-Connect review queue for qualifying My Network suggestions, with configurable mutual-connection limits, editable messages, paced batches, and runtime diagnostics.
- Add Reader and Compact feed controls, adjustable Reader columns, automatic text expansion and translation, and improved Post Drafts integration.

### Bug Fixes

- Keep the Auto-Connect queue outside LinkedIn's page layout so it does not interfere with My Network scrolling or pending connection states.
- Improve Auto-Connect startup, current LinkedIn card detection, accessible-label parsing, and mutual-connection count handling.
- Scope Reader layout and automatic expansion to Feed and My Network so member profiles retain their native layout and Recent activity behavior.
- Map LinkedIn's component-local surface variables and dividers to the LES Night Mode palette.

### Housekeeping / Other

- Refresh extension icons and LES branding assets.
- Add Auto-Connect documentation and parser/threshold tests.
